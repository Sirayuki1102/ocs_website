ワールド管理一覧

ワールド内の全体マップ、各種公共施設の使い方・共有ルールをまとめています。

ワールドマップ

🗺️

Webリアルタイムマップ（Dynmap / BlueMap）

ブラウザからワールド全体の様子がわかります。拠点の場所決めや冒険の経路確認にご活用ください。

🌐 Webマップを開く (準備中 / URLを設定)

公共施設＆サービス使い方

🏰

初期スポーン広場

場所: X: 0, Z: 0（中央広場）

初心者用フリーチェストやエンチャントテーブル、ベッドを完備。どなたでも自由に使用・休憩できます。
🌾

共有公共農園

場所: スポーン東地区

小麦・ジャガイモ・ニンジン・サトウキビなどを自由に収穫可能です。【ルール】収穫したら必ず種や苗を植え直してください。
⚒️

公共製錬所・倉庫

場所: スポーン南地区

高効率かまどや自動仕分け装置を設置。燃料（石炭・溶岩等）の補充にご協力をお願いします。
🚈

中央交通ネットワーク（鉄道・ネザー）

場所: スポーン地下1F

主要拠点や各プレイヤーの村をつなぐトロッコ・ネザーハイウェイ。トロッコは使ったらチェストに戻してください。
🧪

トラップタワー / 経験値トラップ

場所: ネザーハブ経由（北バイオーム）

修繕やレベル上げに利用可能。長時間AFK（放置）の際は他の方への配慮をお願いいたします。
🏪

プレイヤー商店街

場所: スポーン西地区

プレイヤー同士で素材やエンチャント本を取引できるエリア。出店希望の方は運営までお気軽にご相談ください。
📜

公共施設のご利用ルール

みんなで気持ちよく使うために、「使ったら元に戻す」「資源の補充にご協力いただく」ようご協力お願いいたします。壊れてしまった部分や不具合を見つけた場合は、お気軽に運営スタッフまたはDiscordにてご報告ください！
